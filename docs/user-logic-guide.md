# Somikoron - সিস্টেম লজিক, ক্যালকুলেশন এবং এসএমএস অটোমেশন গাইড

এই ফাইলে Somikoron অ্যাপ্লিকেশনের প্রতিটি ফিচারের পেছনের গাণিতিক সূত্র, ডাটাবেজ লজিক এবং এসএমএস অটোমেশন কিভাবে কাজ করে তা বিস্তারিতভাবে বর্ণনা করা হয়েছে।

### ১. গাণিতিক ক্যালকুলেশন লজিক (Calculation Formulas)

সিস্টেমের প্রতিটি হিসাব নিচের সূত্রগুলো মেনে রিয়েল-টাইমে ক্যালকুলেট হয়:

**স্টুডেন্টের ভাড়া বকেয়া (Rent Due Calculation)**
সিস্টেম স্টুডেন্টের ভর্তি হওয়ার তারিখ (Billing Start Date) থেকে আজ পর্যন্ত অতিবাহিত মাসগুলো গণনা করে।
- সূত্র: (অতিবাহিত মোট মাস * মাসিক ভাড়া) + হিস্টোরিকাল বকেয়া (যদি থাকে) - মোট পরিশোধিত ভাড়া
- কিভাবে কাজ করে: ধরুন একজন স্টুডেন্ট জানুয়ারিতে ভর্তি হয়েছে এবং মার্চ মাস চলছে। তার ৩ মাসের ভাড়া যোগ হবে এবং সে আজ পর্যন্ত যত টাকা ভাড়ার জন্য দিয়েছে তা বিয়োগ হয়ে বকেয়া বের হবে।

**খাবারের ব্যালেন্স (Food Balance Calculation)**
এটি শুধুমাত্র 'Non-Package' স্টুডেন্টের জন্য কাজ করে।
- সূত্র: মোট জমা দেওয়া খাবারের টাকা - (মোট খাওয়ার সংখ্যা * বর্তমান মিল রেট)
- কিভাবে কাজ করে: স্টুডেন্ট যদি ৫০০০ টাকা জমা দেয় এবং ১০০ বেলা খাবার খায় (মিল রেট ৪০ টাকা হলে), তবে তার খরচ ৪০০০ টাকা। ব্যালেন্স থাকবে +১০০০ টাকা। খরচ বেশি হলে ব্যালেন্স মাইনাস (-) দেখাবে।

**মোট বকেয়া (Total Due)**
- সূত্র: ভাড়া বকেয়া + মাইনাস ফুড ব্যালেন্স (যদি থাকে)
- কিভাবে কাজ করে: ফুড ব্যালেন্স যদি পজিটিভ থাকে তবে তা বকেয়াতে প্রভাব ফেলে না। শুধুমাত্র খরচ বেশি হয়ে গেলে (মাইনাস ব্যালেন্স) তা মোট বকেয়ার সাথে যোগ হয়।

### ২. এসএমএস স্মার্ট ট্যাগ গাইড (SMS Smart Tags Guide)

এসএমএস টেমপ্লেট তৈরি করার সময় নিচের ট্যাগগুলো ব্যবহার করলে সিস্টেম অটোমেটিক স্টুডেন্টের তথ্য বসিয়ে দেবে:

| ট্যাগ (Tag) | কি কাজে ব্যবহার হবে (ব্যবহারকারীর নির্দেশিকা) |
| :--- | :--- |
| **[নাম]** | স্টুডেন্টের পুরো নাম। এটি স্টুডেন্টকে ব্যক্তিগতভাবে সম্বোধন করতে ব্যবহৃত হয়। |
| **[মাস]** | পেমেন্ট বা মিল লগের জন্য সিলেক্ট করা মাস এবং বছর (যেমন: January 2024)। |
| **[meal_count]** | ওই মাসের মোট কতবেলা খাবার খাওয়া হয়েছে তার সংখ্যা। |
| **[meal_rate]** | সেটিংস পেজে আপনার সেট করা বর্তমান খাবারের রেট (প্রতি মিলের দাম)। |
| **[meal_bill]** | খাবারের মোট খরচ (মিল সংখ্যা × মিল রেট)। |
| **[rent]** | স্টুডেন্টের প্রোফাইলে নির্ধারিত মাসিক রুম ভাড়া। |
| **[previous_due]** | বর্তমান পেমেন্ট করার ঠিক আগ মুহূর্ত পর্যন্ত স্টুডেন্টের মোট কত টাকা বকেয়া ছিল। |
| **[total_payable]** | **সবচেয়ে গুরুত্বপূর্ণ ট্যাগ।** পেমেন্ট করার পর ওই স্টুডেন্টের কাছে বর্তমানে মোট কত টাকা (ভাড়া + খাবারের বকেয়া) পাওনা আছে তা দেখাবে। |
| **[paid]** | বর্তমানে যে পরিমাণ টাকা পেমেন্ট হিসেবে রিসিভ বা জমা করা হয়েছে। |
| **[food_balance]** | খাবারের জন্য জমানো বাড়তি টাকা। যদি স্টুডেন্টের ব্যালেন্স পজিটিভ থাকে তবেই এটি অ্যামাউন্ট দেখাবে, অন্যথায় ০ দেখাবে। |
| **[food_due]** | খাবারের বকেয়া টাকা। যদি খাওয়ার খরচ জমা টাকার চেয়ে বেশি হয়ে যায়, তবে সেই মাইনাস ফিগারকে পজিটিভ সংখ্যা হিসেবে এখানে দেখাবে। |
| **[রুম]** | স্টুডেন্টের বরাদ্দকৃত রুম নম্বর। |
| **[সিট]** | স্টুডেন্টের বরাদ্দকৃত সিট নম্বর। |
| **[building]** | স্টুডেন্ট কোন বিল্ডিংয়ে থাকে তার নাম। |
| **[Hostel Name]** | এসএমএস সেটিংস পেজে আপনার দেওয়া হোস্টেলের ব্র্যান্ড বা অফিসিয়াল নাম। |

### ৩. অটোমেটিক এসএমএস ট্রিগার (Automatic Triggers)

সিস্টেমের ৩টি জায়গায় কাজ শেষ হলে অটোমেটিক এসএমএস চলে যাবে:

1.  **পেমেন্ট এন্ট্রি:** যখনই কোনো পেমেন্ট 'Confirm' করবেন, সাথে সাথে স্টুডেন্টের মোবাইলে পেমেন্ট রিসিট ও বর্তমান বকেয়ার এসএমএস চলে যাবে।
2.  **ভর্তি অনুমোদন (Admission Approval):** নতুন স্টুডেন্টের রিকোয়েস্ট এপ্রুভ করলে তাকে স্বাগত জানিয়ে রুম ও সিট নম্বরসহ এসএমএস পাঠানো হবে।
3.  **এক্সিট সেটেলমেন্ট (Exit Message):** কোনো স্টুডেন্ট হোস্টেল ছেড়ে দিলে তাকে ধন্যবাদ জানিয়ে বিদায়ী মেসেজ চলে যাবে।

### ৪. পিডিএফ এবং প্রিন্ট লজিক (PDF & Print Pattern)

সিস্টেমের 'Download PDF' বাটনগুলো সরাসরি স্ক্রিনশট প্রিন্ট করে না, বরং একটি আলাদা 'Print Layout' কল করে। এটি এ৪ (A4) সাইজে প্রফেশনাল টেবিল জেনারেট করে যেখানে হোস্টেলের নাম বাংলায় (**সমীকরণ ছাত্রাবাস**) প্রদর্শিত হয়।
